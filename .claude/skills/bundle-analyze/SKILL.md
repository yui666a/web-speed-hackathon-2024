# バンドル分析スキル

## 概要

Vite のビルド出力を分析し、バンドルサイズ・依存ライブラリ・コード分割の状態を可視化する。
TBT は配点30点で最大ウェイトなので、JS バンドル削減は最も費用対効果が高い施策。

## 前提条件

- `pnpm run build` 済みで `workspaces/client/dist/` が存在すること

## ワークフロー

### Step 1: 分析スクリプトの実行

```bash
bash .claude/skills/bundle-analyze/analyze.sh
```

オプション：
- `--rebuild`: sourcemap を有効にして再ビルドしてから分析
- `--top N`: 依存ライブラリの表示数（デフォルト: 20）

### Step 2: 出力の読み取り

4つのセクションで構成：

1. **Overall Bundle Size** — 全チャンクのサイズ一覧（gzip 推定値付き）
2. **Dependency Analysis** — バンドルに含まれる重量級ライブラリの検出
3. **Chunk Splitting Analysis** — Vite manifest のエントリポイントと依存関係
4. **Optimization Opportunities** — 巨大チャンク、未ミニファイ検出、総サイズ警告

### Step 3: 施策への活用

分析結果から以下を判断する：
- どのチャンクが大きいか → コード分割の対象
- どの依存ライブラリが残っているか → 除去・軽量代替の候補
- admin 用コードがメインバンドルに混入していないか
- 未ミニファイのコードがないか

結果を perf-propose スキルに引き継いで具体的な施策にまとめる。
